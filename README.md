# BI_VAN Android starter

A black-and-gold React Native / Expo prototype for a short-video social app.

## Run it
1. Install Node.js on your computer.
2. Install dependencies: `npm install`
3. Start Expo: `npx expo start`
4. Install Expo Go on your Android phone and scan the QR code, or use an Android emulator.

## Included in this prototype
- Black-and-gold BI_VAN branding
- Short-video feed UI with like interactions
- Discover categories and follow buttons
- Upload screen with caption publishing into a local demo feed
- Profile and creator-studio entry points
- Demo inbox and message composer
- Notifications screen
- Go Live demo screen
- Settings screen

## Important before publishing
This is a front-end prototype, not a production social network yet. Video selection/upload, accounts, secure messaging, live streaming, push notifications, creator payouts, moderation, and analytics require backend services and provider integrations. The visible demo feed uses placeholder video cards, not actual playable videos. For a public launch, add authentication, database, video storage/transcoding/CDN, reporting/blocking, age-appropriate safety controls, moderation, privacy policy, terms, and secure payment/payout integration.
